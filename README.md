# Expense Analyzer
I build this small Python project to keep track of my expenses and undestand where my money is going.

For now, the program takes expenses by category, calculates the total amount spent, and shows which category I spent the most on.

## What it can do 
-Store expenses by category 
-Calculate total spending
-Find the cayegory with the highest expense
